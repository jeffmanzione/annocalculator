# Anno 117 game data

`anno117-data.json` and the icons in `public/icons/anno117/` are generated by
`src/tools/anno117/convert-params.ts` from `js/params.js` in
[anno-mods/anno-117-calculator](https://github.com/anno-mods/anno-117-calculator), the community Anno 117
calculator by Nico Höllerich (NiHoel) and contributors. That project's data was extracted from the game
files; this app only keeps what a production calculator uses.

## Regenerating

```sh
curl -L -o params.js https://raw.githubusercontent.com/anno-mods/anno-117-calculator/main/js/params.js
npx tsx src/tools/anno117/convert-params.ts params.js
npm test -- --watch=false     # the checks in src/app/games/anno117/game/data.spec.ts
```

The script prints what it kept and what it left out. Check a new game patch's changes in the diff of
`anno117-data.json` before committing.
